# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful and welcoming, assume good intent, give and accept constructive feedback gracefully, and
focus on what is best for the community. Harassment, discriminatory language, personal attacks and publishing
others' private information are not acceptable.

## Enforcement

Report unacceptable behavior privately to the maintainers through GitHub (a private security advisory or a direct
message to a maintainer listed in the repository). Reports are reviewed promptly and confidentially. Maintainers may
remove contributions and temporarily or permanently ban contributors who violate this code, following the
enforcement guidelines of the Contributor Covenant 2.1.
